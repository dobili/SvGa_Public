# Gruppen nach der neuen Ordnung (0.2.144)

Je Gruppe zwei Paarungen gegen die Nm-Stufen um ihre Zahl, 36 Partien, ohne und mit Maia, zwei Teile. Aufruf (im Ordner app/): `PLANORDNER=messplan-gruppen ZIELNAME=gruppen PARTIEN=36 skripte/messe-nach.sh ohne 1` usw. Von Hand aus den Daten vom 26.10.2026 erzeugt.
