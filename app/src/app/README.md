# `app/` – Hülle der App

| Datei                                     | Aufgabe                                               |
| ----------------------------------------- | ----------------------------------------------------- |
| `App.tsx`                                 | Installationsseite oder App, Leiste, Update-Hinweis   |
| `stapel.ts`                               | Navigation als Stapel (rein, getestet)                |
| `navigation.tsx`, `navigationsKontext.ts` | Stapel für React, Zurück-Taste von Android            |
| `offline.ts`                              | Service Worker anmelden, Offline-Fortschritt, Updates |
| `installieren.ts`                         | Installationsdialog von Android, Chrome, Edge         |
| `geraet.ts`                               | Startmodus und Gerätetyp für die Anleitung            |
| `merker.ts`, `version.ts`                 | Kleine Merker, App-Version                            |
