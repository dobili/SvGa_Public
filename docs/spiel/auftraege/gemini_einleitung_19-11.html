Gemini-Aufträge: Einleitung des Spiels (19.11.2026)

Das Spiel beginnt jetzt vor dem Haus an der Birch Lane: Ankunft mit Mama, das Haus, dann das leere Wohnzimmer, in dem Mama die Kiste von Mrs. Whitlock auf den Dachboden schickt. Vier Bilder erzählen das mit. Bis sie da sind, zeigt das Spiel an diesen Stellen nur den Text; sobald ein Bild im Paket liegt, erscheint es von selbst über seiner Zeile.

So geht es

  1. Für jedes Bild einen neuen Chat in Gemini öffnen.
  2. Die Stilvorlage anhängen: ki-roh/stilvorlage.png im privaten Repository (dieselbe wie bei den übrigen Großbildern).
  3. Auf „Prompt kopieren“ tippen und den Text einfügen.
  4. Das Ergebnis nach ki-roh/ legen und dem Hauptchat die Nummern E1 bis E4 nennen. Zuschneiden und Ablegen unter spiel/bilder/ macht der Hauptchat.

Keines der Bilder enthält Schrift. Wo im Motiv etwas steht (Ortsschild, Kistendeckel), bleibt die Fläche leer.
