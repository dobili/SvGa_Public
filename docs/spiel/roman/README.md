# Der Roman zum Schach-Abenteuer

Wunsch des Autors (13.11.2026): Die Geschichte jedes Akts wird einmal als Roman erzählt, so wie ein
Spieler sie erleben könnte, mit Erzähler, Umgebung, Dialogen und Gedanken. Der Roman ist kein
Spieltext. Er ist der **Leitfaden für alles andere**: Wer eine Karte baut, einen Dialog schreibt
oder ein Musikstück auswählt, liest das Kapitel und weiß, wie sich die Stelle anfühlen soll.

## Regeln für den Roman

- **Ich-Erzählung, Vergangenheit.** Der Held erzählt selbst. So bleiben Name und Geschlecht offen
  wie im Spiel. Wo andere den Helden ansprechen, steht der Platzhalter **Robin**; im Spiel steht
  dort der gewählte Name.
- **Grundlage ist die Story-Bibel** (`05_Story_Bibel.md`) mit ihren Szenennummern. Am Kopf jedes
  Kapitels steht, welche Szenen es erzählt, an welchem Ort und in welcher Stimmung
  (`19_Ton_und_Spannungsbogen.md`).
- **Der Roman darf erweitern.** Wo die Geschichte neben den Partien zu dünn ist, kommen Szenen,
  Figuren und Gespräche dazu. Alles Neue ist am Ende jedes Teils unter „Neu gegenüber der
  Story-Bibel“ aufgeführt, damit es ins Spiel übernommen werden kann.
- **Schach wird erzählt, nicht notiert.** Partien stehen als Erlebnis im Text (was hängt, wer
  zählt, wer zittert), ohne Zugfolgen. Die echten Stellungen kommen aus dem Spiel.
- **Kein Verweis auf das Buch** (Entscheidung vom 10.11.2026).
- **Randnotizen für die Umsetzung** stehen in eckigen Klammern am Kapitelende: `[Klang: …]`,
  `[Bild: …]`, `[Karte: …]`. Sie gehören nicht zum Romantext.
